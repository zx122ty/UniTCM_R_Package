# Get omics type statistics

Get omics type statistics

## Usage

``` r
fetch_omics_type_stats()
```

## Value

A [`tibble::tibble()`](https://rdrr.io/pkg/tibble/man/tibble.html) with
columns: `omics_type`, `count`, `percentage`.

## Examples

``` r
if (FALSE) { # \dontrun{
fetch_omics_type_stats()
} # }
```
