# unitcm: R Client for the UniTCM Traditional Chinese Medicine Platform

Provides functions to query the UniTCM API <https://UniTCM.cn/api/v1/>,
covering herb exploration, compound/ADMET data, disease-formula
associations, TCM ontology, transcriptomics, and gene-disease analysis
(MIDAS).
