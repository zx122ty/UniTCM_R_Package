# List origin sources

Returns the top 50 formula origin sources by frequency.

## Usage

``` r
list_origin_sources()
```

## Value

A [`tibble::tibble()`](https://rdrr.io/pkg/tibble/man/tibble.html) with
columns `value`, `label`, `count`.

## Examples

``` r
if (FALSE) { # \dontrun{
list_origin_sources()
} # }
```
