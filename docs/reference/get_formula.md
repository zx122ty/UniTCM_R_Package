# Get a single formula by order ID

Retrieve full detail for one formula from the Disease-Formula Atlas.

## Usage

``` r
get_formula(order_id)
```

## Arguments

- order_id:

  The formula order ID (integer or character).

## Value

A named list with 30+ fields.

## Examples

``` r
if (FALSE) { # \dontrun{
get_formula(1)
} # }
```
