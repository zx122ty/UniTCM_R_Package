# Fetch ontology statistics

Fetch ontology statistics

## Usage

``` r
fetch_ontology_stats()
```

## Value

A named list with fields: `total_entities`, `total_level1`–
`total_level4`, `total_relations`, `total_mappings`, `categories`.

## Examples

``` r
if (FALSE) { # \dontrun{
fetch_ontology_stats()
} # }
```
