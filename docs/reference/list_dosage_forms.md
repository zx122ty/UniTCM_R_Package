# List dosage forms

Returns the top 50 dosage forms by frequency.

## Usage

``` r
list_dosage_forms()
```

## Value

A [`tibble::tibble()`](https://rdrr.io/pkg/tibble/man/tibble.html) with
columns `value`, `label`, `count`.

## Examples

``` r
if (FALSE) { # \dontrun{
list_dosage_forms()
} # }
```
