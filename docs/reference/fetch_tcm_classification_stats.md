# Get TCM classification statistics

Get TCM classification statistics

## Usage

``` r
fetch_tcm_classification_stats()
```

## Value

A [`tibble::tibble()`](https://rdrr.io/pkg/tibble/man/tibble.html) with
columns: `classification`, `count`, `percentage`.

## Examples

``` r
if (FALSE) { # \dontrun{
fetch_tcm_classification_stats()
} # }
```
