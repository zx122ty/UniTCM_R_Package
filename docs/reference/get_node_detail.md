# Get node detail

Get node detail

## Usage

``` r
get_node_detail(node_id)
```

## Arguments

- node_id:

  Node ID.

## Value

A named list with fields: `id`, `type`, `label`, `label_cn`,
`properties`, `detail_url`.

## Examples

``` r
if (FALSE) { # \dontrun{
get_node_detail("H:UNITCM_H001")
} # }
```
