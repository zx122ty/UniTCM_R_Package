# Get Transcriptome Hub statistics

Get Transcriptome Hub statistics

## Usage

``` r
fetch_transcriptome_stats()
```

## Value

A named list with fields: `total_datasets`, `total_organisms`,
`total_tcm_entities`, `total_analysis_modules`, plus distribution data.

## Examples

``` r
if (FALSE) { # \dontrun{
fetch_transcriptome_stats()
} # }
```
