# Get a single transcriptome dataset

Get a single transcriptome dataset

## Usage

``` r
get_transcriptome(dataset_id)
```

## Arguments

- dataset_id:

  The dataset ID (e.g. `"TCMtrans00001"`).

## Value

A named list with 35+ fields.

## Examples

``` r
if (FALSE) { # \dontrun{
get_transcriptome("TCMtrans00001")
} # }
```
