# Set the UniTCM API base URL

Set the UniTCM API base URL

## Usage

``` r
set_base_url(url)
```

## Arguments

- url:

  A character string. The base URL for the UniTCM API, e.g.
  `"https://unitcm.qfxulab.com/api/v1"`.

## Value

Invisible previous URL value.

## Examples

``` r
if (FALSE) { # \dontrun{
set_base_url("https://unitcm.qfxulab.com/api/v1")
} # }
```
