# Get a single Target2NP interaction record

Retrieve the full detail for one compound-target interaction record.

## Usage

``` r
get_target2np(record_id)
```

## Arguments

- record_id:

  Integer record ID.

## Value

A named list of interaction fields.

## Examples

``` r
if (FALSE) { # \dontrun{
get_target2np(1)
} # }
```
