# Get a single herb by ID

Retrieve full detail for one herb from the Herb Explorer.

## Usage

``` r
get_herb(herb_id)
```

## Arguments

- herb_id:

  The UniTCM herb ID (e.g. `"UNITCM_H001"`).

## Value

A named list with 31 fields including cross-reference IDs.

## Examples

``` r
if (FALSE) { # \dontrun{
get_herb("UNITCM_H001")
} # }
```
